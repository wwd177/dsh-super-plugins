# 跨skill固定回归

## 保存一份当前来源

项目已有案例目录时复用。记录每条原始需求、必要原始材料、预期行为、实际生产入口与消费者，以及当前允许的验证层级。新缺陷加入同一目录；历史运行只留结果和必要证据，不复制整套工程来制造新“覆盖数”。

固定回归用于防止已经发现的问题复发，不能替代实际skill产出测试。对开放语言结果先看完整正文是否完成任务，再用机械检查辅助；正文快照只防未经复核的版本变化，不是语义判分器。

## 可选的历史文字案例

2026-10-20 的媒体维护项目曾使用 `work/media-skill-regression/CURRENT.json`。它是该项目的文字回归目录，不是任意当前项目已存在的全局资源。只有当前任务确实需要该案例、项目内存在 catalog 且原始来源和脚本已核对时才使用；没有 catalog 时按本次原始需求建立合适验证，不复制旧统计或重建旧案例来凑覆盖。

本技能的 `scripts/run_corpus.py` 是该历史格式的专用执行器，固定执行 `check_chain.py` 和 `reentry.py`；不是任意项目的通用测试器。用它加载已核对且符合该格式的目录：

```powershell
python <技能目录>/scripts/run_corpus.py --catalog <项目目录>/work/media-skill-regression/CURRENT.json
```

命令只执行该项目明确列出的本地维护脚本，在隔离的临时副本里生成验证结果；不调用供应商，不上传，不生成媒体。它检查来源一致性后运行现有结构/正文版本检查和合成续接重放，只保留紧凑运行日志与结果，退出非零即失败。目录不是可信代码的自动安装器，只运行已审查、已固定的本项目脚本。

这些脚本仍是机械验证。历史阶段记录与回接视图由维护者编写/复用，不能算实际模型独立执行。当前案例数、版本和结果以本次实际 catalog 与输出为准。实际生产者评估需要单独提供原始需求并生成真实文本输出；模型、版本、输入、实际输出、判分方式和耗时均须明确，不能回填虚构指标。

## 媒体续接案例的适用行为

- 换轴后按目标机位重建投影，保留当前段号、世界锚点和解剖手，不重新引用旧视角首帧。
- 指尖触柄尚未握稳 → 本段收握 → 持剑出招；收握之后再续接不重新触柄、抛剑或起跳。
- 克隆/绑定剑半消散 → 装备按其既定事件退出 → 身体退出，后续不恢复完整；独立真实剑不随克隆消失。
- 遮挡交剑 → 新持有者持续持有，直到指定的新交接/投掷；显式拾取回到原主人属于合法变化。
- 中途回接携带所有尚未完成的事件，例如C4/e退出后c仍须落R、d仍留Q。
- 保留高速、急停、空中支撑与连续出招；稳定不等于减速、待机或减少招数。

若发现未覆盖的新失败，先复现并确定产生偏差的层，再加入能区分修复前后的案例。不得把输出格式化器、期望状态副本或全文相等检查描述为独立语义验证。
